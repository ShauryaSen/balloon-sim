# Lab group talk

Slides are in `slides.md`, written in [Slidev](https://sli.dev) markdown. Speaker notes go in the `<!-- -->` at the end of each slide.

    cd talk && npm install && npm run dev    # opens http://localhost:3030, reloads on save
    npm run export                           # talk.pdf

- `<Todo>...</Todo>` is a grey box for a figure we still have to make.
- `v-click` / `<v-clicks>` reveal things one click at a time.
- Figures live in `public/figures/` and are referenced as `/figures/name.png`.
